# Pohjanpiha Festival website

A fast, simple website for Pohjanpiha Festival, a two-day music festival in Alavus every July.

## Pages

- `index.html`: home page with festival info and ticket link
- `lineup.html`: who plays, on which stage and when
- `area.html`: the area and accessibility information
- `contact.html`: a form for sending questions
